Host enrollment

On another authorized Ubuntu/Debian Linux machine, install the monitor agent with the server URL and this instance's token:

curl -fsSLO https://raw.githubusercontent.com/vibhvesh/CanberraAi-chat-/main/agent/install-sentinel.sh
sudo bash install-sentinel.sh --server https://YOUR-DOMAIN --token YOUR_SENTINEL_AGENT_TOKEN

The VPS installer sets up its own Sentinel agent. Remote desktops connect outbound to the server; no inbound desktop port is needed.
